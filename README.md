# Lunaris AOSP for Redmi Pad Pro 5G / POCO Pad 5G (`ruan`)

Official Lunaris-AOSP bring-up and device adaptation for Xiaomi Redmi Pad Pro 5G / POCO Pad 5G (SM7435 / parrot).

Maintainer: **hecker3432**

## Specifications
- **SoC**: Qualcomm Snapdragon 7s Gen 2 (SM7435)
- **Target OS**: Lunaris-AOSP (Android 16 / 16.2)
- **Codename**: `ruan`

## Automated Cloud Build (GitHub Actions)
This repository includes a pre-configured GitHub Actions workflow to compile Lunaris-AOSP:
1. Navigate to the **Actions** tab in this repository.
2. Select **Build Lunaris AOSP (ruan)**.
3. Click **Run workflow** (select `userdebug` or `user`).
4. Once completed, your `recovery.img`, `boot.img`, and flashable `lunaris_ruan-*.zip` will be posted under **Releases**.
